Blender 5.3の
3DGSネイティブ対応を
1,720万粒の渋谷で検証する

ロケハン3Dの中村です。
Blender 5.3で、3D Gaussian Splatting（3DGS）がアドオンなしで読み込み・描画できるようになります。
渋谷スクランブル交差点の1,720万粒の全景データで、描画速度とメモリ、VFXの素材としてどこまで出せるかを確かめました。
結論は、背景プレートとプリビズには十分使える一方、ライト・深度・書き出しの3点で止まるです。

PLYを読み込む→ カメラを決める→ EEVEE / Cyclesで描画→ EXRで合成へ
この記事で得られるものBlender 5.3の3DGS対応で何ができて、どこで止まるかを、実データの数値と画像で判断できます。対象は公式デイリービルド（5.3.0 Alpha、2026年9月18日版）です。正式リリースは11月10日の予定で、それまでに挙動や数値が変わる可能性があります。

01 何が変わったか──PLYを読み込むだけで3DGSになる

File > Import からPLYかSPZを選ぶだけで、Point Cloudオブジェクトとして読み込まれます。
種類は「3D Gaussian Splats」になり、Workbench・EEVEE・Cyclesのすべてで描画できます。
1粒ごとに次の属性を持ちます。

属性内容
position位置
scale大きさ
rotation向き（Quaternion）
radiance:base基本色と不透明度
radiance:sh_0〜球面調和の係数（視点で変わる色）
  • 球面調和は3次（45係数）まで読み込まれ、描画にも反映されます。
  • 座標は自動で変換され、Zが上の状態で配置されます。
  • ジオメトリーノードのDelete Geometryで範囲外を消すと、3DGSのまま切り抜けます。
  • Set Point Cloud Typeノードで、普通のポイントとの切り替えもできます。

03 描画性能──1,720万粒でも1枚2秒前後

粒数読み込みEEVEE（初回／2回目以降）Cycles GPU（初回／2回目以降）
10万0.01秒0.69／0.19秒1.26／0.48秒
100万0.08秒0.75／0.32秒0.80／0.65秒
400万0.31秒1.08／0.59秒1.23／1.04秒
1,720万1.6秒2.41／1.73秒2.78／2.57秒

1,720万粒でも、EEVEEで1枚1.7秒、Cyclesで2.6秒です。
カメラを回す24フレームの連番は、EEVEEで1枚1.52秒、Cyclesで2.47秒でした。
メモリはRAMが3.2GB、GPUメモリの増加が約5GBに収まります。
1,720万粒の.blendは919MBで、保存0.34秒、開き直し0.6秒で扱えます。

リリースノートには「性能は理想的ではない」とありますが、この環境では実用的な速さです。
GPUが弱い環境や、球面調和を多く持つデータでは結果が変わります。
また、間引いたデータは粒のすき間が目立つため、実案件では全量で使います。

05 本番で止まる4つの点

1つ目は、ライトが効かないことです。
スプラットは光を出す素材として描画され、撮影時の光が色に焼き込まれています。
強いライトを当てても色は変わらないため、夜景に変えるような背景のライティング変更はできません。
CGを置くときは、撮影時の光の向きにCG側のライトを合わせます。

2つ目は、深度パスに穴があることです。
スプラットのある画素のうち7.5〜8.4%で深度が記録されません。
粒が半透明の部分で、深度が無限遠になるためです。

3つ目は、書き出すと色が消えることです。
PLYに書き出すと中身が0粒のファイルになり、USDでは位置・大きさ・向きは出ますが色と不透明度が入りません。
HoudiniやNukeへ3DGSのまま渡すことはできないため、Blenderで描画してEXRで渡します。

4つ目は、Apply Transformで見た目が崩れることです。
オブジェクトの変形のままなら崩れませんが、変形を適用すると粒の大きさが元のまま位置だけ広がり、すき間だらけになります。

マルチレイヤーEXRは1パス1ファイルで出す今回のアルファ版では、複数のパスを1つのEXRにまとめるとCombinedしか入りません。メッシュだけのシーンでも同じなので、3DGSの問題ではありません。コンポジターのFile Outputノードでパスごとに別のEXRにすると、深度や法線も書き出せます。

06 まとめ

Blender 5.3の3DGS対応で、制作に使える範囲はこの3行に収まります。

  • 背景プレート・プリビズ：1,720万粒でも1枚2秒前後で描画でき、画質も十分です。
  • CGとの合成：前後関係・ホールドアウト・被写界深度はそのまま使えます。影はシャドウキャッチャーで取り出します。
  • 本番の壁：ライトが効かない、深度に穴がある、書き出すと色が消える、Apply Transformで崩れる、の4点です。

SPZの読み込みと、本物の球面調和を持つデータでの見た目は、正式リリース後に改めて確かめます。
