Import 3DGS into Blender and render background footage

A tested Shibuya workflow: installation, import, image-quality settings and video output.

01 Why bring 3DGS into Blender?

I’m Nakamura from Locahun3D. This guide covers using our Shibuya Scramble Crossing 3DGS data as a background in Blender.

Importing the scan lets you frame shots with Blender cameras and export stills or camera animation. We tested the actual appearance of buildings and signs, rather than treating a successful import as proof of image quality.

02 Our choice: BlendSplat with EEVEE

For this Shibuya dataset, our choice is BlendSplat with EEVEE.

It preserves building surfaces and sign shapes while using normal Blender cameras and rendering. The steps below reproduce this setup.

BlendSplat is an asset library built with Geometry Nodes and materials, not a separate Blender fork. This recommendation is specific to our dataset and tested setup. It is not a quality ranking of every product, including paid packages we have not obtained.

Official releases / Creator’s product page

03 Download and installation

  1. Download the BlendSplat library and extract it to a permanent folder.
  2. In Blender, open Edit → Preferences → File Paths → Asset Libraries and add the extracted library.
  3. Check that its nodes and materials appear in the Asset Browser.

We tested Blender 5.1.2. Register an asset library rather than installing the archive as a conventional add-on. Check compatibility on the release page before installation.

04 Import the splat and render through a camera

Connect the import and display nodes

Add Geometry Nodes to a mesh object, then add the library’s splat.import and splat.display groups. Connect the import Splat output to the display Splat input, then the display output to Group Output Geometry.

  1. Set the import Path to the Gaussian-splat PLY.
  2. Select Billboard (EEVEE) in the display group.
  3. Assign splat.shader.billboard to BillboardMat.
  4. Select EEVEE and start without a size-filter node.

Use BlendSplat’s import node rather than stopping at Blender’s standard PLY import. This test uses the PLY alone, without an OBJ.

Frame and export

Place a camera inside the scan, set its lens and orientation, and check a still with F12. Add camera keyframes, choose the output folder, resolution and frame range, then use Render → Render Animation to export a PNG sequence. Encode the sequence using your normal video workflow.

05 A 360-degree view from the crossing

The camera stays in the middle of the crossing and turns through a full circle. This shows the background from inside the scene rather than from a distant aerial viewpoint.

Compare the buildings, signs and road as the camera rotates. The video is 1280×720 at 24 fps (240 frames over 10 seconds), with a 24 mm camera lens setting. Playback speed is not a measurement of viewport performance.

06 Quality settings and remaining limitations

Do not remove every large splat

A size filter can remove building surfaces along with unwanted splats. For this dataset, removing that filter preserved the buildings and signs. Start without the filter, then edit genuinely unwanted regions.

Adjust render samples for grain

BlendSplat uses dithering for transparency. This sequence uses 64 EEVEE render samples. Increase samples if fine grain remains distracting.

Missing capture information stays missing

Moving-person remnants, thin structures and sparsely captured regions can still break up. More render samples cannot accurately reconstruct information that was never captured. This test uses the captured background color; it does not establish normal-mesh lighting and shadow behavior.

08 AI finishing is a separate step

For a different time of day or season, first export the Blender image, then treat AI processing as a separate finishing stage. AI-enhanced images are not evidence of native Blender rendering quality.

The UE5 / XGRIDs and AI article contains Shibuya examples and limitations involving text and signs. Those examples originate in UE5, not this Blender test.

09 Summary: start with this setup

For this Shibuya dataset, start with BlendSplat + EEVEE, without a size filter. Register the library, load the PLY, check a camera still, then render a sequence.

Use the 360-degree video to judge whether the background meets your shot’s needs. If defects remain conspicuous, adjust the framing or plan additional finishing.
