Using purchased 3DGS data
in Blender

This is Kou from Locahun3D.
Every property purchase includes an OBJ mesh and point-cloud (PLY) files. A customer asked whether these can be opened in Blender, so we imported each file ourselves and checked what actually works. Along the way we also found a free tool that displays the colored 3DGS correctly, so we're covering that too.

Short answerFor checking shape or taking measurements, the OBJ mesh is the easiest to work with. If you want to see the colored 3DGS inside Blender, a free tool called BlendSplat displays and renders it correctly, keeping the photoreal look. Blender on its own, and another add-on we tried, didn't produce a usable colored view — but BlendSplat is light to install and fast to display.

Three files come with every purchase

Every property purchase includes three files:

  • ① OBJ — a standard 3D mesh made of polygon faces.
  • ② Point cloud (PLY, smaller file) — an internal reference used for alignment during capture. It isn't meant to be used directly.
  • ③ Point cloud (PLY, larger file) — the 3DGS data, which reproduces a photoreal look using colored splats.

01 ① OBJ — the geometry imports cleanly

OBJ is a format Blender supports natively, so it opens with no extra setup. For the Shibuya Scramble Crossing data, the buildings and roads across the whole intersection loaded correctly.

Because there's no color or texture, this file isn't meant for checking the look of a location. It's meant for taking measurements or using the shape as a base for further modeling.

02 ② Point cloud (PLY) — opens, but shows nothing

Blender can open the point-cloud file too, but no color appears, and the screen stays empty.

3DGS data carries more than point positions — it also stores each point's color, how transparent it is, and the shape of its splat. Blender doesn't have a built-in way to read that, so it imports only the positions and discards everything else.

03 ③ Another add-on — still no usable color

We also tried a free add-on built specifically for displaying 3DGS in Blender. The import itself went well — it correctly converts the color, transparency, and splat-shape data into Blender's own data.

This add-on wasn't usable in practiceThe import finished without errors, and all the necessary data was present. Even so, the actual view showed nothing but gray points — the colored look never appeared.

04 ④ BlendSplat — displays the color correctly

Looking further, we found a free tool called BlendSplat. It handles 3DGS using only Blender's built-in features (geometry nodes and EEVEE), with no separate external engine to run. Using it, we got a colored display — sharp enough to read the text on signage — and could export it as an image.

Setup is just extracting the files and registering the folder as a Blender asset library — no extra installation. Importing is light, and it produced a correctly colored result reliably.

A couple of things to noteSparse or edge areas of a scan can leave behind some colored noise-like specks. If that bothers you, filtering out oversized splats cleans up the look.

Summary — pick the tool for the job

MethodWhat Blender showsBest used for

Use the OBJ file when you need the shape as a modeling or measurement base. Use BlendSplat when you want to view and work with the colored scan inside Blender itself. If you'd rather skip any install and just check the look in a browser, the Locahun3D viewer is also available.
